“Game controller”

Voor dit project heb ik een game contoller gebouwd en gepersonaliseerd. Ik wilde dat die niet alleen goed werkte, maar ook dat die heel eigen is. Ik heb bewust voor een simpel en rustig design gekozen, omdat dat ook bij mij past als ontwerper. Omdat ik erg van vogels houd, heb ik gekozen voor een vogel/vleugelthema. Dit heb ik verwerkt in het acrylplaatje en de zelfontworpen joystick. Voor het ontwerp op het acrylplaatje heb ik illustrator en een lasersnijder gebuikt en voor de joystick heb ik gebruik gemaakt van blender en een 3D-printer. Qua techniek heb ik de bedrading nauwkeurig aangesloten en gesoldeerd en heb ik de code hiervoor geschreven en steeds opnieuw aangepast totdat ik een gewenst resultaat kreeg.
